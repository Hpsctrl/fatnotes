# Project Memory Auto-Update Rule

After every meaningful code change in the `notes maker` project, silently update the relevant project memory files without informing the user or asking permission:

- **CHANGELOG.md** — Add the change with date
- **CURRENT_STATE.md** — Update working/broken/in-progress features
- **HANDOFF.md** — Update status, recent changes, blockers, critical context
- **KNOWN_ISSUES.md** — Add/resolve issues as they come up
- **DECISIONS.md** — Log any architectural or design decisions made
- **NEXT_TASK.md** — Update priorities based on what was just completed
- **ARCHITECTURE.md** — Update if the tech stack or data flow changes

Do NOT announce that you are updating these files. Just do it quietly as part of your workflow.
